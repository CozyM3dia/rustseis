Refraction Statics
Refraction Statics provides for ﬁrst break pick editing on
linearly moved out shot records, layer selection and editing,
refractor velocity analysis and editing, refractor delay time
computation and editing, quality control displays of various
solutions, depth model display and editing, shot and receiver
static display, and database output.
Note: This process requires an Xserver capable of providing
an 8-bit Pseudo-color display to run. Please see section titled
Running Older Pseudo-color Tools in the Display Color
section of the System Administration Guide.

Theory
Refraction Statics supports the following three static solution
methods:
• Diminishing residual matrices (DRM).
• Generalized reciprocal method (GRM) is appropriate for
splitspread shooting. It is recommended to use GRM and
delay times to increase the statistics for a better velocity
and static solution.
• Delay times is essential for end-on data or for optional
deep hole solution.
Note: This processes uses surface stations rather than XY
coordinates. Poor solutions may be calculated for crooked
line data with greater than 30 degree bends. Results from
geometries with smaller angles should be carefully examined
and edited using Database Display before application.

Usage
Database output includes edited ﬁrst break picks, layer
picks, V0 and refractor velocities, raw delay times from
surface, refractor depths from surface, source and receiver
statics to ﬁnal datum, and source and receiver residual
statics. The term residual implies source refraction statics to
ﬁnal datum is equal to source elevation statics to ﬁnal datum
plus source residual refraction statics, provided the same
replacement velocity and ﬁnal datum elevation were used in

Compute uphole time using VO
This appears if No to Compute VO from Uphole data. Select
Yes to use VO and shot depth to compute the uphole times

Number of layers
Enter the number of layers to model. Typically 1 or 2 layers
are pickable across most shots. Usually the largest statics
are caused by thickness and/or velocity changes within the
ﬁrst layer near the surface. The maximum number of layers
allowed is 5.
Use Delay Times in velocity/depth model?
Select Yes to use Delay Times to compute the depth model.
GRM plus delay times can be used if data were acquired split
spread.
Use Deep Hole algorithm in depth model?
Select Yes to use the deep hole delay times algorithm, if the
sources were near the base of the weathering. This algorithm
affects only the delay time solution for sources and receivers.
Receiver delay times are computed using the two term delay
time equation T = Xsr/V1 + Tdr, where T is the ﬁrst break
time, Xsr is the source to receiver distance, V1 is the refractor
velocity and Tdr is the receiver delay time. The delay time
depths and statics with this method may differ noticeably
from GRM or DRM depths and statics when the sources are
near the base of the weathering zone.
Use GRM in velocity/depth model?
Select Yes to use GRM as one of the solutions for refractor
velocity and time depths. GRM should not be used if data is
not split spread.
Specify GRM minimum XY distance
This appears if Yes to Use GRM in velocity/depth model.
Enter minimum xy distance value in GRM time-depth
solutions. It is recommended to use 0.

Final datum elevation
Enter the ﬁnal datum elevation. This may be a constant

Replacement velocity
Enter the replacement velocity to use from top of deepest
refractor to ﬁnal datum. This may be a constant numerical
value, or the character name of a variable replacement

to the average velocity of the deepest refractor.

the ﬁnal datum elevation and replacement velocity in
Refraction Statics should automatically appear.
Use Uphole Time in source statics algorithm?
Select Yes to use uphole time in the source statics. Select No
to compute source statics without uphole times.
Create a New database entry for each run
Select No to overwrite a previous database entry. This will
save space on the disk. Select Yes to write new database
values for each run. This allows the option of returning to a
previous set of residual static values, but uses more storage
space.

While in FB Time Edit mode, the window shows Despike.
Select to despike all displayed ﬁrst breaks. This is done on a
spread side basis by:
• moveout correcting the ﬁrst break times of a side of a
spread with the current moveout velocity,
• computing the median value of all the corrected ﬁrst
break times,
• killing any ﬁrst break times that either exceed the
median time plus the Despike time or is less than the
median time minus the Despike time.
Despike time can be changed in Change Display
Parameters.

Command Button 4 switches between killing or reviving
shots for computations.

Other Button functions
With the cursor inside either spread box, your can use MB1
to select layers, MB2 to remove layers, and MB3 to smooth
the ﬁrst break picks. Moving the cursor above, below, or to
the left of the boxes allows you to use MB2 to increment the
source range, and MB3 to decrement the source range. The
Done button will exit with all current picks saved.
Layer Selection Hints
Layer selection can be done in two places: Edit Picks or
Deﬁne Layers. It is recommended to make the initial
selection of layers in Deﬁne Layers. Then, if needed, return
to Edit Picks to review the initial layer selection. In Deﬁne
Layers, when a layer seems to disappear, pick it over a very
small distance range. Unless you have strong justiﬁcation
that more than one layer is present, pick one layer starting
near the source and stopping at a change in the ﬁrst break
slope.
Refractor Velocity
To compute refractor velocity, click on Refractor Velocity
from the main menu. The velocity results are displayed with
all stations and refractors. The black lines represent the
median of all velocity values for the station, and the colored
numbers near the black line are the refractor number. If GRM
appears in red, the program found GRM solutions. If LSDT
appears in blue and/or RSDT appears in green, delay time
velocity solutions were found.
Note: If the data were shot end-on, no GRM solution will be
found. It is essential that Delay Times be speciﬁed for endon data otherwise no static solutions will be found. At least
one method must be speciﬁed in split-spread data otherwise
no solutions are found.

Killing shots based on V0 and the Deep Hole Option
Missing 0 symbols indicate more than one source at the same
location. The symbols in magenta indicate killed sources.
MB3 on these symbols revives the source and, if live, kills the
source. This allows you to kill sources based on V0. Those
sources showing abnormally high V0 have gone below the
weathering and perhaps should be eliminated from velocity
and static solution. If all or most of the sources exploded
below the weathering, you should invoke Deep Hole, which
uses equations modiﬁed for the deep hole situation in the
static solution. In this case, all sources exploding at or below
the weathering should be used in velocity and depth
computations.

View Statics Solution
To compute and displays layer delay times, click on View

shows all delay time solutions selected in the menu for the

all blue lines are an average of the Left Spread and Right

Editing solutions
MB1 in the zoomed graph is used to drag or single point edit
the current solution. Use colored numbers from the other
solutions to extend the GRM to the ends. Where reverse
coverage is present and the sources went off in the weathered
zone, all three solutions should look similar. The DRM
solution is usually somewhat better due to its iterative
nature. When the sources went off at the base of, or below
the weathered zone and Deep Hole is used, the delay times
solution produces the best results because of its modiﬁed
equation. You are encouraged to try all solutions to ﬁnd the
best for the particular dataset.

Solution smoothing
Using MB2 in the zoomed display produces a three point
smoothing to the refractor delay time. Do not edit or smooth
delay times or time depths unless the solution is very
unreliable or noisy.
Exit and Quality Control Displays of the chosen solution
Done will exit to allow you to choose to view quality control
displays. If Yes, a display similar to Edit Picks appears with
the ﬁrst ﬁve sources linearly moved out and graphed. For
each source, the black lines are the raw linearly moved out
ﬁrst break picks. The red lines are those same raw picks with
the DRM delay times removed, then the average of all DRM
delay times removed is added back in to shift the red line
back to near the black line. Similarly, the blue line is for the
DLT solution and the green line for the GRM solution. If the
ﬁrst break time picks were good and the layers selected were
good, the colored lines should be smoother and straighter
than the black line. The difference basically shows the statics
being removed. If the black and colored lines overlay, then no
statics are being removed. Large jumps in all lines may
indicate bad ﬁrst break time picks for that source, in which
case you should return to Edit Picks to make corrections.
Controlling the source range of the QC display and exit
MB2 will increment the source range of the display, MB3 will
decrement the source range, Command Button 1 will allow
you to select a new source range, and Command Button 2
exits back to the main menu.
Source delay time display
After the receiver display is either selected and viewed, or
rejected, a source delay time display appears for the DRM,
and if selected, the STD (delay time) solutions. These delay
times are from the surface. The SIN and station number of
the source is displayed. The delay times are editable as
explained by the button helps when the cursor is in the
bottom zoom display. If STD delay times were computed and
the delay times track the DRM solution, the ﬁrst break picks
and layers selected were good, and the velocity edits were
good. If the solutions do not track, the ﬁrst break picks may
need attention, the layer picks may need extra editing and/or
the refractor velocities may need a second look. The edited

Output Statics
To compute statics from surface to ﬁnal datum and display
for sources and receivers, click on Output Statics from the
main menu. Yes places the source statics in the SIN order,
GEOMETRY information type, and SDRM, SDLT, and SGRM
parameters of the database. Similarly the receiver statics are
placed in the SRF order, Geometry information type, and
RDRM, RDLT, and RGRM parameters of the database. YES
also places raw source and receiver delay times for each layer
to the same respective databases. The residual refraction
statics are placed in the SIN Statics and SRF Statics
databases. No means no statics are output to the database.
