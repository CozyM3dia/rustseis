Time Varying Trim Statics
Time Varying Trim Statics creates time varying trim statics
for windows along the traces in a CDP gather.

Theory
This process is useful for cleaning up a brute stack which will
be used as model traces for External Model correlation statics
or for removing residual moveout before a brute stack. Refer
to Horizon Trim Statics.
Trim statics are computed for each time window. After the
statics are computed for each time window, the statics
applied at each sample by interpolating the statics between
the window centers above and below the sample. The static
values of the ﬁrst and last window are extended to the
beginning and the end of the trace.
If you are trying to remove residual moveout on gathers, you
are encouraged to use the macro bin option. The macro bin
option computes the trim static for a super gather produced
by summing across CDP gathers. The computed trim statics
are then applied to each trace. This process does not write to
the Ordered Parameter Files.

Parameters
Window interval
Enter the time interval to compute a different trim statics.
Window half length
Enter the length of the window at each time interval. A
triangular taper is applied to the windows.
Maximum trim static
Enter the maximum trim static value. Computed trim statics
values will not be larger than this value.
Minimum live samples in gate (in percent)
Enter the percentage of minimum live samples in a gate.
Windows with fewer live samples than this value are not used
in statics computations.
Use macro bins?
Enter Yes to create macro bins across CDP gathers.
Number of CDPs in a macro bin
This appears if Yes to Use macro bins. Enter an odd integer
representing the total number of CDPs in a macro bin.
Secondary header word for macro bins
This appears if Yes to Use macro bins. Select offset, binned
offset, or the absolute value to stack traces from neighboring
CDP gathers.
Center of an AOFFSET bin
This appears if Yes to Use macro bins. Enter the center of
any bin. The other bins centers will be an integral number of
bin spacings from this value.
AOFFSET bin spacing
This appears if Yes to Use macro bins. Enter the bin center
spacing. The number of bins is automatically computed.
