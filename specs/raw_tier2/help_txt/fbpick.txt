First Break Picking
First Break Picking automatically picks ﬁrst breaks for
refraction statics analysis.

Theory
The ﬁrst break is the ﬁrst recorded signal attributable to
energy generated by the seismic exploration source. First
breaks on reﬂection records are normally used for
determining a near surface statics model. This ﬁrst break
picker is designed to work in two modes, dynamite or
Vibroseis.
The automatic ﬁrst break picker uses an algorithm known as
stabilized power ratio picking. This algorithm is particularly
effective for impulsive sources, and is quite fast. Because of
the more complex problem, the option for non-impulsive
sources runs more slowly. It is however, also very effective on
the impulsive sources. It uses the envelope of the amplitudes
rather than the actual amplitudes.
The algorithms use the ratio of the power in a leading or lookahead gate to the power in a trailing, or look-back, gate. This
value is usually at a maximum when the trailing gate is in the
pre-ﬁrst break noise and the leading gate is in the ﬁrst break
signal.

Usage
One potential problem with this type of ﬁrst break picker is
the occurrence of false picks in the pre-ﬁrst break noise due
to short duration impulses such as footsteps or wind gusts.
To avoid these false picks the power ratio is stabilized by
adding a percentage of the power of the entire trace to the
power in the trailing gate. This is why the algorithm is called
a stabilized power ratio picker. A zero stabilization factor
results in no stabilization being applied.
The lengths of the leading and trailing gates are
automatically determined from your estimate of the ﬁrst
break energy envelope width. A heavily stabilized pick is
made ﬁrst. Higher stabilization factors (greater than 1.0) may
result in late picks, while low stabilization factors (less than

You can supply gate limits. These will be used to limit the
segment of the data in which the program will search for ﬁrst
breaks. You can specify to pick these gates in Screen Display
or Trace Display, and put them into the database.
As an alternative way of guiding the ﬁrst break picks, you can
specify a minimum and maximum refraction velocity. These
values are used to limit pick searches.
The ﬁrst break picks are put into the trace headers and
applied using Header Statics. Use Database/Header
Transfer to load the picks from the database into the trace
headers.
Note: The picker cannot pick ﬁrst break times less than a few
samples. Please remember this for short offset traces.

Parameters
Type of data we’re picking
There are two possible choices to describe the type of data
being analyzed:
• Dynamite: input data is dynamite or other impulsive
source. Use Dynamite for data with good, sharp ﬁrst
breaks.
• Vibroseis: input data is Vibroseis or other non-impulsive
source. Use Vibroseis for data with emergent or noisy
ﬁrst breaks.
First break energy envelope width
Enter the average width of the energy envelope of typical ﬁrst
break signals. This value should be given in ms.
Power ratio stabilization factor
Enter a percentage of the power of the entire trace to add to
the trailing window. This factor helps stabilize the leading-totrailing power ratio used as a picking criterion. The suggested
range is 5.0%-40.0%.

Shift the pick down
Shift data to improve pick consistency in noisy data.
• No: does not shift the ﬁrst break pick. This is the actual
onset of the seismic energy.
• Peak: shifts the pick down to the nearest peak below the
actual ﬁrst break pick.
• Trough: shifts the pick down to the nearest trough below
the actual ﬁrst break pick.
Filter to apply before shift
This appears if Pick or Trough to Shift the pick down.
Enter a bandpass ﬁlter to apply to the trace before the pick is
shifted. This ﬁlter is applied to identify the peak or trough to
pick. The ﬁlter is speciﬁed as four frequencies: F1,F2,F3,F4
as for a normal bandpass ﬁlter. Leave this ﬁeld blank if you
do not want to apply a ﬁlter before shifting the pick.
Specify a pick search gate
Select Yes to deﬁne a time and space-variant gate in which to
search for picks. You can manually input these gate values or
pick the gates in Screen Display. These picks are entered into
the database, and recalled to guide the picking algorithm.
These values are used to limit pick searches.
Get pick search gates from database
This appears if Yes to Specify a pick search gate. Select Yes
to retrieve a ﬁle from the database. Remember that there may
be more than one list of time gates in the database for this
line. Select No to enter the values manually.
Select Time Gate Parameter FILE
This appears if Yes to Get pick search gates from database.
Select a pick search gate parameter ﬁle.
Select Primary Time Gate Header Word
This appears if No to Get pick search gates from
database.Select a header word as the Primary key for
specifying the pick search time gates. You may select from
the main list of header words or the alternate list.

Select Secondary Time Gate Header Word
This appears if No to Get pick search gates from database.
Select a header word from the Headers menu as the
Secondary key for specifying the pick search time gates. This
parameter is optional.
First break pick search gate
This appears if No to Get pick search gates from database.
Enter the locations of the time gates in the following format:
Primary Gate Location Value: Secondary Value: Search Gate/
Example: 1:-5280:1200-1550 / 1:0:0-300 / 1:5280:1200-1550 /

Minimum refraction velocity
This appears if No to Specify a pick search gate. Enter the
minimum refraction velocity to limit ﬁrst break pick
searches. Enter 0.0 to disable this feature.
Maximum refraction velocity
This appears if No to Specify a pick search gate. Enter the
maximum refraction velocity to limit ﬁrst break pick
searches. Enter 0.0 to disable this feature.
Pick output locations
Select pick output locations from the following choices:
• Header only: outputs the picks to the trace headers
only. If this option is selected, this process can be run in
the absence of a database.
• Header and database: outputs the picks to both trace
headers and to the TRC database.
Create a NEW database entry for picks
This appears if Header and database to Pick output
locations. Select No to overwrite a previous database entry.
This will save space on the disk. Select Yes to write new
database values for each run. This allows the option of
returning to a previous set of ﬁrst break pick values but
obviously uses more storage space.

Enter 4 digit ID number
This appears if Yes to Create a New database entry for each
