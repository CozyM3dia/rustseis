Crooked Line Geometry Spreadsheet
Crooked Line geometry assignment gives a truer picture of
the subsurface than other geometry packages because it
takes into account the angular relationships between the
shots and their receivers
This section lists and describes the parameters associated
with each spreadsheet, as well as the parameters associated
with Bin. You need to focus on three things:
• entering all required ﬁeld geometry into the Setup,
Receivers, Sources, and Patterns spreadsheets
• binning your data
• ﬁnalizing the Database

Entering All Required Field Geometry
You will need to select and complete the Setup, Receivers,
Sources, and Patterns spreadsheets from the menu bar. You
will then select Bin to bin your data and ﬁnalize the
Database. Use TraceQC to quality control your data:

In Crooked Line Geometry Assignment you complete all
spreadsheets as you would for a 2D Land Geometry
assignment. In the binning interface, after assigning
midpoints, select Deﬁne crooked binning grid. A series of
windows appear for you to deﬁne the crooked line binning
grid. The following sequence gives a general overview of how
the OPF database is created using crooked line:
• Midpoints representing the scatter of live shots and
receivers are calculated.
• Segments are tracked through the midpoints.
• Bins are hung along these segments.
• Bin and ﬁnalize the database as you would for a 2D Land
Geometry Assignment.

Gap Deﬁnition Methods
In ProMAX® Crooked Line, Gap Chan Dlt and Gap Size Dlt
columns have been added to the Sources spreadsheet for
deﬁning a gap for a shot location. A gap is created in the ﬁeld
by not recording into a given number of receiver stations
immediately preceding and following the shot (or source
array) location. This reduces the surface wave noise that
would likely contaminate and overdrive the geophones at
these receiver stations. With the addition of the Gap Chan Dlt
and Gap Size Dlt columns, you have two methods for deﬁning
a gap in a receiver pattern:
Method 1 - Static Gap Deﬁnition: Deﬁne a gap by the jump
in the receiver station numbers within the pattern deﬁnition
entered in the Patterns spreadsheet. A new pattern deﬁnition
is required whenever the gap changes size or changes
location within the same range of channel numbers. This

channel numbers.

Initial XYGraph screen

In Crooked Line Geometry Assignment, there are two options
for deﬁning the track and binning the data: Simple and Full.
Simple is the default option and provides all the necessary
tools to deﬁne the track and bin the data for most crooked
lines. However, this option uses a subset of the tools found in
the Full option. This option modiﬁes the behavior and
defaults of crooked line to simplify the processes of deﬁning
the track and generating the bins.
Full is used if the line is severely crooked or requires detailed
modiﬁcations to the track and/or bins. A full sweep of tools
are available for this option.
Within the Initial XYGraph screen, select File/Crooked then
Full or Simple. If Full appears, then your current mode is
Simple. Likewise, if Simple appears, then your mode is Full.
You can toggle between the two modes at any time during an
edit session.

Control points/ Src-Rec Offset. White or black could be
used as well for better visibility of the track. After the
midpoints are displayed, select Track from the menu bar.

TraceQC
The TraceQC button opens the TRC OPF spreadsheet. This
spreadsheet is a window into the database TRC OPF which
can actually contain more attributes than are shown by this
spreadsheet. The database TRC OPF contains all trace
speciﬁc attributes for this line. Some of the attributes are
geometry related, while others are not. Only attributes
pertaining to the your particular type of geometry are shown
in the TRC spreadsheet. Most of the attributes in this
spreadsheet are internally computed and are only for quality
control viewing. Attributes which cannot be edited have an *
in the column name. For example, CMP X* cannot be edited,
whereas FB Pick can be edited.
Columns in the TRC OPF spreadsheet are initialized by one
or more of the following steps:
• running Extract Database Files
• completing Assign Midpoints in Bin
• completing Bin Midpoints in Bin
• importing UKOOA data using File/UKOOA Import
• using File/LOOKUP Indexing
The following list describes all TRC OPF spreadsheet
columns.

ProMAX® datasets in this line. The Mark Block number
maps all TRC OPF attributes associated with it to a single trace in a dataset. The geometry speciﬁc attributes
are loaded into the trace headers when Inline Geometry
Header Load is run. The remaining TRC OPF attributes
can be loaded into the traces headers during subsequent
processing.
See Column and Row Selection for mouse button
