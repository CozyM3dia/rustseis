Surface Consistent Deconvolution
Surface Consistent Deconvolution uses any combination of
source, receiver, offset, and CDP components for power
spectrum calculation and deconvolution.

Theory
The recorded seismic signal may be considered as the
convolution of the source signal with the instruments, the
geophones, and the response of the earth. The earth response
includes some undesirable effects, such as reverberation,
attenuation, and ghosting. The objective of deconvolution is
to estimate these effects as linear ﬁlters, and then design and
apply inverse ﬁlters.
Surface consistent deconvolution is based on the concept
that a seismic wavelet can be broken down into its source,
receiver, offset, and CDP components. For land data, all four
components are normally used in the decomposition, but
only the shot and receiver portions are applied. Since the
receivers are in motion in marine acquisition, the common
receiver grouping is less suited to this type of data. However,
the common receiver domain is still important in areas with
highly variable bottom conditions. When using this process
on marine data, it is common either to perform a simple shot
decon, or to use the shot and offset terms.
Note: The SRF database must be present and complete to
decompose or deconvolve with the SRF term.

Usage
Surface Consistent Deconvolution is an iterative tool,
meaning traces from the ﬂow input tool are passed into the
process for analysis, and then automatically passed again for
decon application.
Note: JavaSeis datasets cannot be input to this module.
Only ProMAX datasets are supported. Use the Gated SC
Decon modules sequence for JavaSeis datasets.
After deconvolution has been applied to the traces, they are
reinserted in the ﬂow, one at a time. There can be any
number of processes in the ﬂow between the input step and

After the four components are separated, the deconvolution
operator is designed using the power spectra from the desired
components in the Wiener-Levinson algorithm. This
algorithm uses a least-squares approach to design the
optimal operator. You can select either a minimum phase
spiking or predictive operator.
Prior to operator design, a Hanning taper is applied to both
taper on and taper off the input data derived from the time
gate. Beginning and ending tapers are equal to one-half the
operator length. In the case of multiple decon operators, onehalf the minimum operator length is used.

Parameters
Choose version
Select a faster memory version or slower disk version. The
choices are:
• Memory version uses the fast memory version for small
datasets (.5M traces or less).
• Disk version uses the slower disk version for large
datasets (.5M traces or more).
Display spectra and autocorrelations?
Select Yes to display spectra and autocorrelations. During
execution, screen prompts appear for:
• number of stations per screen
• scale factor
The spectra and autocorrelations are displayed by station,
except for offset, which is displayed in number of stations. All
power spectra are displayed with respect to the minimum
and maximum values of the entire input dataset.
Select display DEVICE
This appears if Yes to Display spectra and
autocorrelations. Select This screen to display spectra and
autocorrelations from the device you are working. You can
also enter the name of another recognized device. Spectra
may only be displayed for 2D land surveys.
Start CDP
Enter the starting CDP, but not less than the minimum CDP
of the input data. Use this value to make a subset of the
input data for analysis and application.
End CDP
Enter the ending CDP, but not greater than the maximum
CDP of the input data. Use this value to make a subset of the
input data for analysis and application.
Note: Traces outside the CDP range are passed without
decon application.

• Predictive applies Wiener-Levinson predictive decon for
each selected component.

deconvolution operator.

Limit offsets in decomposition?
Select Yes to restrict a range of offsets in decomposition. It
may be possible to better approximate the seismic wavelet by
restricting the offsets because of the effects of ground roll or
high amplitude ambient noise.
Minimum absolute offset
This appears if Yes to Limit offsets in decomposition. Enter
a minimum absolute offset. Traces with offsets less than this
value are not included in calculation.
Maximum absolute offset
This appears if Yes to Limit offsets in decomposition. Enter
a maximum absolute offset. Traces with offsets greater than
this value are not included in calculation.
Decon operator length (ms)
Enter the deconvolution operator length, in ms.
Operator white noise level
Enter the white noise value, in percent, to use for the
operator calculation. This prewhitening percentage
represents the percentage of white noise that is added to the
original spike response, in order to stabilize the inverse ﬁlter
calculation.

Apply user speciﬁed taper?
Select Yes to apply a user speciﬁed taper length to the design
gate prior to autocorrelation. Select No to use a taper of 1/2
the minimum operator length.
Taper length in ms
This appears if Yes to Apply user speciﬁed taper. Enter the
taper length to be applied to each end of the design window
prior to autocorrelation. The value is speciﬁed in ms.
Window rejection factor
Enter the factor by which to multiply the operator length. Any
gate which contains less live samples than the result is
eliminated for calculation.
Apply a bandpass ﬁlter after decon?
Select Yes to apply a bandpass ﬁlter to the data after the
application of the deconvolution.
Bandpass ﬁlter frequency values
This appears if Yes to Apply a bandpass ﬁlter after decon.
Enter the frequency bandpass ﬁlter to apply to the data after
deconvolution. The ﬁlter is speciﬁed by a set of four corner
frequencies, separated by dashes. The values may be integers
or real numbers. They represent, sequentially, the 0% and
100% points of the low-cut ramp, and the 100% and 0%
points of the high-cut ramp, in Hz. These ramps are formed
by cosine tapers (Hanning windows) in the frequency domain.
