SRME Macro
This tool performs 2D Surface-Related Multiple Estimation
(SRME). Input data are shot ensembles that have been
regularized in the sense that the traces within each shot are
regularly sampled from 0 to the maximum offset by a
constant increment.
This regularization can be done by "SRME Regularization".
The output data are shot ensembles that contain the multiple
estimates.
The normal ﬂow of data is:
-> recorded shots ->
SRME Regularization ->
SRME Macro
-> predicted multiples
-> interleave the original shots and predicted multiples ->
SRME Un-Regularization ->
-> interleaved original shots and unregularized
predicted multiples
->interleaved original shots + unregularized predicted multiples ->
SRME Match Filter ->
-> interleaved original shots + match ﬁltered multiples
SMRE Adaptive Subtraction ->
-> shots with multiples removed
This module provides an effective way of estimating all
surface-related multiples for adequately sampled and
properly prepared 2D marine data. The algorithm used is
derived in the seminal papers by workers at ARCO and Delft
University.

The ideal preprocessing of 2D data includes the following
steps.
1. Source signature deconvolution
2. Source and receiver deghosting
3. Direct arrival suppression
4. Regularization so that offsets need to range from zero to
the maximum offset with a constant increment within
shot ensembles.
5. Approximate geometrical spreading correction by
multiplying by (T)**(1/2)

Usage
Input data are regularized shots -- regularized in the sense
that the traces within each shot are regularly sampled from 0
to the maximum offset by a constant increment.
Output is the multiple estimate as shot ensembles at the
original shot locations but with the traces within the shots
still in regularized positions.

Parameters
Process multiple lines?
Select Yes to perform SMRE rpocessing on multiple lines.
Header entry for line change
Appears if Yes for Process multiple lines?. Click MB1 to
select a header entry that speciﬁes a line change.
Perform parallel processing?
The SRME can be run in parallel on several remote machines
simultaneously.
Speciﬁes the machines to run processes on
Appears if Yes for Perform parallel processing. Specify the
list of hosts to use for the PVM parallel. Leave blank if
submitted to the Queue and the host list will be ﬁlled in
automatically from the host list generated by the Queue.

The maximum trace time to process (ms).

The maximum number of shots in this dataset.
Maximum Frequency to process
Maximum frequency in the multiple estimate (hz). 0.0 implies

Trace Header ﬁle name
The input trace headers are temporarily saved on scratch
disk while the SRME module is running. This is the name of
the ﬁle. The ﬁle is deleted when the job ﬁnishes.
Flip shot direction?
Select Yes if the order of the shots in the input data set is
equivalent to the source PUSHING the cable.
Length of spatial taper (traces)
Spatial taper length (number of traces).
Frequency taper
Frequency taper (% of maximum frequency). The taper
applied is this amount before the Maximum frequency and
this amount after the Maximum frequency.
Shot/Receiver Spacing Ratio
Used to determine the interpolation required to get the shot
spacing equal to the group spacing.
Three options are available:
• 1:1-Shot/Receiver Spacing Ratio is 1:1
