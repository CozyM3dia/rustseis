Tau-P Inverse Transform
Inverse Tau-P transforms a slant stack back to the time and
offset domain using the inverse Radon transform.

Theory
See the Tau-P Transform helpﬁle.

Usage
The input data must have a slowness header value deﬁned.
The header values are assumed to be in units of
ms/kilometer or ms/kilofoot. The header values are stored in
these units to enable Screen Display to show a sufﬁcient
number of signiﬁcant digits. When specifying slowness
parameter values, remember to use the appropriate units.
This process can change the data length, and/or the number
of traces in an ensemble. Pay close attention to the time or
Tau value stored in sample one of the output trace. You may
ﬁnd it necessary to apply a static shift after the inverse Tau-P
Transform.

References
Stoffa,P.L., Buhl, P., Diebold,J.B., and Wenzel, F., 1981, Direct mapping of seismic
data to the domain of intercept time and ray parameter. A plane wave decomposition: Geophysics, 46, 255-267.

Parameters
Minimum Slowness (ms/km orms/kf)
Enter the minimum slowness value of interest. This value will
be in units of ms/kilometer or ms/kilofeet. The value may be
negative.
Maximum slowness (ms/km orms/kf)
Enter the maximum slowness value of interest. This value
will be in units of ms/kilometer or ms/kilofeet. The value
may be negative.

Place a Window on Tau
Select Yes to place a window on Tau. Samples at Tau values
outside the window will be ignored. Select No, the default, to
use the minimum Tau generated by Tau_P.
Minimum Tau of interest (ms)
This appears if Yes to Place a Window on Tau. Enter
minimum Tau value to be output in the slant stack. This
value has units of ms and can be negative.
Maximum Tau of interest (ms)
This appears if Yes to Place a Window on Tau. Enter a
maximum Tau value to be output in the slant stack. This
value has units of ms and can be negative.
Minimum time of interest (ms)
Enter the minimum time of interest, in ms. Times less than
this value are zeroed, with no tapering. Note: The ﬁrst sample
of the output trace will be at this time.
Maximum time of interest (ms)
Enter the maximum time of interest, in ms. Times greater
than this value are zeroed with no tapering.
Maximum number of output TX offsets
Enter the maximum number of TX traces to output, if a
database does not exist. This number should be the same as
the maximum input to forward Tau P. If a database exists,
the value will be taken from the database for the sort order of
the data being processed.
Tau_P Inversion mode
Select the Tau_P Inversion mode from either:
• Original: Transform back to the original ensemble. This
option attempts to invert Tau-P traces back to their
input X-T ensembles, using header and database information.

• User deﬁned X: Transform to a user deﬁned set of offsets. After using this option, it may be necessary to redeﬁne the geometry of the traces.
Enter a list of offsets (m or ft.)
This appears if User deﬁned to Tau_P Inversion mode.
Enter a list of offsets, using the example in the editor.
Zero offset for stacked data (X)
This appears if User deﬁned to Tau_P Inversion mode.
Enter the x location to use for zero offset. For stacked
sections, Tau-P calculates pseudo-offset values from the
trace header x,y pairs. When performing the inverse
transform, be sure to use the same X coordinate as was
utilized by the forward transform.
Zero offset for stacked data (Y)
This appears if User deﬁned to Tau_P Inversion mode.
Enter the y location to use for zero offset. As with the X
coordinate of the pseudo-offset origin, the Y value should be
the same as the one that was used for the forward Tau-P
transform.
Apply mute after Tau_P inversion?
Select Yes to reapply mutes after the inverse Tau-P
transform. As with many two dimensional processes, the
Tau-P transform pair will create nonzero valued data samples
in originally muted zones.
