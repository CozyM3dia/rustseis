SEG-Y Output
SEG-Y Output writes out industry standard SEG-Y tapes, it
can also write out frequently requested non-standard
variations of SEG-Y.

Theory
This process offers the option of writing a SEG-Y disk image
ﬁle in IEEE format. The disk format allows you to retain some
of the header information for later use, while writing out a
SEG-Y format disk ﬁle.
Read the Conﬁguring ProMAX® Tape Device Information
section in the System Administration guide for system speciﬁc
information about tape device conﬁguration, settings, long
blocks, installation, and a detailed description of the tape
subsystems.
Read the Seismograph Instrument Parameters section for
information on transduction, coding, and skew corrections.

Parameters
Type of SEG-Y
Select the type of data storage to be used for the output data.
The choices are:
• Standard writes a standard SEGY tape.
• Sierra writes a Sierra SEGY disk ﬁle (ﬁxed record
length).
• Landmark TOD writes a Landmark TOD SEGY disk ﬁle
(ﬁxed trace length)
• Western writes a Western SEGY disk ﬁle (variable record
length).
• Charisma writes a Charisma SEGY disk ﬁle (ﬁxed record
length).
• MS-DOS writes a MS-DOS SEGY disk ﬁle (variable
record length).

File Number on tape
Enter the ﬁle number to write to tape when there are multiple
SEG-Y ﬁles on one reel. SEG-Y standard is one ﬁle per tape
and putting more than one ﬁle per tape violates the SEG-Y
standard. However, it is commonly done, especially when
stacked data is written to tape. This option allows you to
output a selected ﬁle to tape by counting the ﬁles on the tape.
For example, if you want to skip the ﬁrst two datasets on a
tape and write a third dataset, give a value of 3 for this
parameter. You do not need to position the tape at the EOF
marker before writing, our software will automatically skip
over the correct number of ﬁles to write the ﬁle number you
speciﬁed.
New ﬁle on line segment end?
Select Yes to write multiple SEG-Y ﬁles to tape based upon
the LSEG_END ﬂag. When a trace is written, where the trace
header value for LSEG_END =1, another SEG-Y ﬁle is started
beginning with the next trace. This option allows you to write
seismic lines to separate ﬁles. SEG-Y Output will set the
LSEG_END ﬂag at line number changes (LINE_NO) and/or
ﬁle boundaries.

Desired trace format
Select the type of data sample words to be written out. When
using the MS-DOS option only the 2 byte integer format is
used so this parameter is not shown. The choices are:
• IBM Real is 4-byte IBM Floating Point SEG-Y.
• 4 byte Integer is 4-byte Integer SEG-Y.
• IEEE Real is 4-byte IEEE Floating Point SEG-Y (nonstandard).
• 2 byte Integer is 2-byte Integer SEG-Y.
• 1 byte Integer is 1-byte Integer SEG-Y (non-standard).

Use the Rev 1 time scalar?
Select Yes to apply the time scalar ( bytes 215-216 in the Rev
1 header) to the statics, lag times and mutes (bytes 95-114)

ignored if the input is not SEG-Y Rev1 or higher. (See SEG-Y
Rev 1 header table.)
Maximum time to output
Enter the maximum time in ms to output. The default, 0,
outputs all the available data.
Remap SEGY headers?
Select Yes to output/override/remap SEG-Y trace header
values.
Output/override trace header entries
This appears if Yes to Remap SEGY headers. Select the
header entries to output or override in the SEG_Y trace
header, using user-supplied format and position. Header
entries must exist prior to output. Format can be 2I, 4I, 4R
IBM, 4R IEEE, 8R IEEE. Position is anywhere inside the 240
byte SEG_Y trace header. For example, bytes 233-240 could
be used since they are currently unassigned in both the
standard SEG-Y and Rev 1headers.
An override entry consists of four ﬁelds plus a / at the end of
each entry. Each ﬁeld is separated by a comma.
Example:
rms_amp, 4R,IEEE, 233/

Field 1: rms_amp is the name of the header word. This word
must already exist in the header prior to output. This ﬁeld
can be 1 to 8 characters.

Field 2: 4R is the format of the value in the SEG-Y header.
This ﬁeld can be an 2I (2 byte integer), 4I (4 byte integer), 4R
(4 byte real), or 8R (8 byte real). This ﬁeld must be 2
characters.
Field 3: IEEE is the data representation of a real value in the
SEG-Y header. This ﬁeld is valid for 4R and 8R values only.
This ﬁeld can be IBM for IBM real values or IEEE for IEEE
real values. At this time, 8R can be IEEE only.
Field 4: 233 is the starting byte position within the SEG-Y
header to write the override value. This ﬁeld can be 1 to 3
characters.
Examples:
sou_sloc, 4I, 181/nav_sloc, 4R,IBM, 185/
