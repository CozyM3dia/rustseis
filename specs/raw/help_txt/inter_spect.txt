Interactive Spectral Analysis
Interactive Spectral Analysis computes and displays
spectral estimates for interactively selected subsets of traces.
The spectral displays can be conﬁgured both interactively
and from menu.

Theory
Interactive Spectral Analysis uses Fourier Transforms to
compute the average power spectrum, the F-X power
spectrum, and the average phase spectrum of an interactively
selected subset of the data.

Usage
While you are using Interactive Spectral Analysis, you can
dynamically change the trace sort by using the Interactive
Data Access (IDA) tool. This tool must be turned on in Disk
Data Input.
Power
The average power spectra is calculated by performing an
FFT on the input traces. The sum of the amplitude spectrum
samples is equal to the mean squared sum of the input data
values, thereby normalizing the spectra. The amplitude
spectra is then squared to obtain the power spectra for
display purposes.
The power spectra can be displayed as raw values, as a
percentage of the deﬁned reference power, or as dB down
from the reference power. If you set the reference power to a
negative number, it will be reset to the maximum power
sample in the spectrum.
dB is deﬁned by:
dB = 10 log (P/PREF) where:
PREF = reference power
P = measured power
All Logarithms are to base 10.

Signal
The signal spectra for the input dataset is calculated by using
each trace of the amplitude spectra calculated above, and
cross-correlating adjacent traces. These signal traces are
summed, then normalized to the number of input signal
traces. and the square root is calculated.
The algorithm for the signal spectra calculation assumes ﬂat
reﬂectors. For example, at zero lag, the cross-correlation of
the amplitude spectra represents the signal spectra.
The signal traces are normalized according to the display
used for the power spectra. For example, if raw power equals
amplitude spectra squared, the signal spectra is also squared
before display to view traces relative to the power spectra.
Noise
Noise is the result of subtracting the signal trace from the
amplitude trace.
Phase
Various options to shift the zero time of the transformed
samples are available. A time shift of the input data is
equivalent to a linear phase shift of the spectrum. This is how
the program applies the time shift. You can also specify the
linear phase shift slope.
The program offers the option to unwrap the phase values.
The phase unwrapping algorithm adds multiples of 360
degrees to the phase values to make the phase spectrum as
continuous as possible.
Pre-Fourier Transform Taper
You have the option of applying a tapered time window prior
to the Fourier Transform. This tapering is recommended,
since tapering the time window reduces edge effects from the
Fourier transform. The choice of taper methods includes
Hanning, Bartlett, Boxcar and Hamming. You can specify the
percentage of the window which is to be ﬂat.

analysis. The spectral displays are automatically
updated for each new selection.
• Multiple Subsets interactively selects multiple subsets
for analysis from the Data Selection window. A new

Primary header for sorting and trace label
Select the primary header for analysis. Select None for the
primary trace label to depend on the choice of secondary
trace label. The header is set to Trace Number or Ensemble
Number if None is selected for the secondary trace label.
Note: For poststack data, you must select CDP for the
primary header and None for the secondary header. The
traces are sorted and located by this header value, so the
header label should be unique for each trace. Traces with
non-unique labels are overlain in the trace and F-X displays,
but their Spectra is still correct.
Secondary header for sorting and trace label
Select the secondary header for analysis. Select None to not
display a secondary trace label.
For poststack data, the secondary header label should be set
to None. Traces with non-unique labels are overlain in the
trace and F-X displays, but their Spectra is still correct.
Display the average power spectrum?
Select Yes, the default, to display the average power
spectrum. Select No to not display the average power
spectrum. However this can be dislayed later with
Show/Hide.
Note: These headers must exist in the input dataset.

displays. This can be interactively changed during the
analysis session. The choices are:
• dB Power displays power in dB down from the reference
power. This is the default.
• Percent Power displays power spectra as percentage of
the reference power.

Time Shift
This appears if Time Shift to Time, sample or linear or no

Number of samples to shift
This appears if Sample Shift to Time, sample or linear or

Unwrap the phase spectrum?
Select Yes to unwrap the phase. Select No to leave the phase
display limited to +/- 180 degrees. Unwrapping the phase
spectrum removes the discontinuities at +/- 180 degrees. It
will make the phase curve continuous. If the phase spectrum
is the average of many traces, the unwrapped phase
spectrum will be the average of the individually unwrapped
phases.
Display the selected trace data?
Select Yes to display the selected trace data. Select No to not
display the selected trace data at this time. However, you can
display trace data later with Show/Hide.
Display the F-X power spectrum?
Select Yes, the default, to display the F-X power spectrum.
The F-X power spectrum is a color contour plot of the power
spectra of the individual traces. Select No to not display the
F-X power spectrum at this time. However, you can display FX power spectrum later with Show/Hide.
Note: The color scale used to display the F-X Power spectrum
can be customized using Color Editor from the Spectral
Analysis Window menu.
Display the Pre-FFT time window?
Select Yes to display the pre-FFT. Select No, the default, to
not display the average phase spectrum at this time.
However, you can display the average phase spectrum later
with Show/Hide.

Pre-FFT time window TAPER type
Select the type of taper to apply to the window before the FFT.
Using a taper reduces FFT edge effects. The choices are:
• Hanning applies a cosine taper with edge value = 0.0.
This is the default.
• Bartlett applies a linear taper with edge = 0.0.
• Hamming applies a cosine taper with edge value = 0.0.
• Boxcar merely truncates the window.
Percent ﬂat for the pre-FFT time window
Enter the percentage of the pre-FFT time window which is not
tapered. For example, if you set this value to 80%, then the
window is tapered over the ﬁrst 10% and the last 10% of its
length. Enter 100.0 for no taper.

Set power display ranges automatically?
Select Yes, the default, to automatically set the power display

Interactive Display
Interactive Spectral Analysis computes spectra from
subsets of the data which you can select interactively. There
are three ways to select subsets of the data: simple selection,
single subset selection and multiple subset selection. The
layout of the spectral analysis window is different for each of
these methods. Most of the displays in the Spectral Analysis
window can be shown or hidden from both the ﬂow menu and
interactively using Visibility under the View pulldown menu.
The best method and window layout depends on the task you
perform.
