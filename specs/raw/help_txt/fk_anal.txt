F-K Analysis
F-K Analysis works with F-K Filter to design and quality
control the application of the F-K ﬁlters to seismic data.

Theory
In this process, you will select the ﬁlter parameters. F-K
Filter will then apply this ﬁlter to an entire or partial dataset
in batch mode. F-K Analysis is only limited to the design and
parameter testing of arbitrary polygon ﬁlters.
F-K analysis displays data in T-X (conventional time-space)
domain, F-K (frequency-wavenumber) domain, F-X
(frequency-space) domain, and T-K (time-wavenumber)
domain. The display may be conﬁgured to show all four of
these domains, T-X and F-K together, or the individual
domains of T-X and F-K by themselves.
For a discussion about the difference between conventional
F-K ﬁltering and the ProMAX® F-K ﬁlter method, see F-K
Filter.

Usage
A velocity tool shows a line through the cursor and indicates
the velocity of this line at the bottom of the display. If the line
is selected in the T-X domain, a line of this same velocity is
shown in the F-K domain display, and visa-versa. The
velocity of a line from the origin to the cursor position is
shown even when the velocity tool is not activated.
Data in all four domains may be displayed in variable
area/wiggle trace, color pixels, or variable density gray scale
modes. When the program is started, the T-X panel will be in
variable area/wiggle trace mode with a linear amplitude
scale. The other domains will be displayed as color pixels and
either a dB (logarithmic) or linear amplitude scale can be
selected from the menu for these displays.
Filters are designed by drawing a polygon on the F-K domain
display. The polygon may not self-intersect or overlap itself.
There is no limit on the number of points used to deﬁne a
polygon. If two regions must be edited, a single polygon
should be used which connects the two regions with a

corridor of negligible width. It may be easier to deﬁne a single
polygon around events which are aliased (wrap around knyquist) if k=0 is plotted on the left side of the screen.
After a polygon has been deﬁned, the impulse response and
the ﬁltered input data for the corresponding ﬁlter may be
examined. The ﬁlter is computed from the polygon
analytically as a T-X domain ﬁlter. The T-X ﬁlter is designed
for a speciﬁc size (samples in time and traces in offset), and
may be windowed using elliptical Hanning tapers. The
smaller the T-X ﬁlter, the less attenuation and smoother the
response of the resulting F-K ﬁlter. The larger the ﬁlter used,
the more execution time will be required.
Stronger tapering is recommended for smaller ﬁlters. That is,
if a ﬁlter is designed with a time length of 100 ms and a
spatial extent of 10 traces, the end samples of the ﬁlter will
be relatively large. Tapering with a percent ﬂat of 50 to 80
percent may be required for an acceptable response.
The polygon parameters for the ﬁlters are written to the
database using the table name supplied in the menu. If an
old table is input, it will be updated with any new polygons or
old polygons which have changed. Any new polygon table will
overwrite an old table of the same name. Polygon table names
must be supplied to the menu before execution of this
program.
Note: If the T-X display puts the near trace at the far relative
offset, use offset as the secondary trace header on Disk Data
Input and specify the correct order for the offsets.
You must be aware that data input to F-K Filter must have
the same sort applied for it to be processed in the same
manner as with F-K Analysis. That is, if the data are sorted
by offset on input to F-K Analysis and parameters are chosen
for ﬁlters to be applied to the data, then the data must also
be sorted by offset for input to F-K Filter or else the output
will be unpredictable.
Note to GeoQuest users: Seismic traces imported from a
GeoQuest database are sorted by LINE_NO and FRN_TRNO
(Foreign Trace Number), but may or may not have CDP
numbers in their headers. This tool needs to have CDP
numbers in the trace headers. If CDPs are not in the headers,
use Trace Header Math to set CDP numbers equal to
FRN_TRNO. CDPs will now equal the trace number displayed

Distance between input traces
Enter 0.0 to automatically calculate the trace spacing
provided input ensembles are shot, receiver, or CDP ordered,
and a database exists. The trace spacing is calculated by:
[[current fold/shot fold] x shot interval] for CDP and receiver
ordered ensembles
the receiver interval for shot ordered ensembles

Otherwise, enter the actual trace spacing.
Starting display conﬁguration
Select the starting display conﬁguration from one of four
options:
• TX-TK-FX-FK displays four panels of TX, TK, FX, and
FK.
• TX-FK displays two panels of TX and FK.
• TX-Only displays a single panel of TX data.
• FK-Only displays a single panel of FK data.
Any subsequent displays are displayed with the same
conﬁguration the ﬁrst time they are selected. The display
conﬁguration can be changed during program execution.
Each of the three displays: Input Data, Impulse Response,
and Filtered Output can have a different conﬁguration.
Position of zero wavenumber in display
Select the position of zero wavenumber (k=0) at either the
Center or the Left side of the display. This applies to the T-K
and F-K displays. This value may not be changed
interactively during program execution.
Position of zero frequency in display
Select the position of zero frequency (f=0) at either the Top or
Bottom of the display. This applies to the F-X and F-K
displays. This value may not be changed interactively during
program execution.

Plot FK, TK, FX panels in dB or Linear
Select to plot FK, TK, FX panels in either:
• DBScale plots using a logarithmic dB scale.
• Linear plots using a linear amplitude scale.
The TX domain data is always plotted with a linear scale. This
value may not be changed interactively during program
execution.
Initial TX gain setting (percentile)
Enter the percentage of the input amplitudes to set TX gain.
Enter 100 to not clip the maximum amplitude of the input
data. Enter 99 to clip one percent of the amplitudes. Usually
99 or 98 will give a well-balanced display with 1 or 2 percent
of the amplitudes clipped.
Initial FK maximum gain setting (db)
Enter the upper limit for color scale in the FK display panel.
Specify a dB gain value (an amplitude of 1 is 0 dB) if the plot
mode is dB or a maximum amplitude value if the plot mode is
linear. This value can be changed interactively during
program execution, but the minimum value cannot. Set the
same value on several executions of F-K Analysis, to compare
FK displays using the same color scales.
Initial FK minimum gain setting (db)
Enter the lower limit for color scale in the FK display panel.
Specify a dB gain value (an amplitude of 1 is 0 dB) if the plot
mode is dB or a minimum amplitude value if the plot mode is
linear. This value may not be changed interactively during
program execution.
Enter 0 for both the maximum gain and minimum gain to set
the maximum gain to the maximum of the data, and the
minimum gain will be 100 dB less than the maximum or the
minimum value of the data, whichever is greater.
Percent ﬂat for trace ramping
Enter a percent to taper the edge traces prior to K-space
transform to minimize the FFT edge effects. The program will
attempt to remove the effect of this ramp after the F-K

Select mute polygon table
Select a mute polygon table from the parameter ﬁle menu.
Leave Invalid if no table exists. You can add a new table, if
table output is desired.
A new polygon table will contain polygon speciﬁcations for
those ensembles which had polygons deﬁned on them. Each
of these polygons will deﬁne a new ﬁlter for F-K Filter. F-K
Filter will linearly interpolate the ﬁlters deﬁned by these
polygons.
If an old polygon is read in, only the polygons which exactly
correspond to ensembles displayed in this execution of F-K
Analysis may be edited. Ensembles must match the type and
number exactly.
Mode of F-K ﬁlter operation
Select the mode of F-K ﬁlter operation from:
• Reject rejects the polygonal region selected for an F-K
ﬁlter and passes the rest of the F-K plane.
• Accept passes this region and rejects the rest of the F-K
plane.

elliptical Hanning taper from the center of the ﬁlter to the
edge of the ﬁlter in time and offset. Enter 100.0 to not apply
tapering of the ﬁlter. Enter 80.0 to give a Hanning taper to 10

Time length of F-K ﬁlter (ms)
Enter the time extent of the F-K ﬁlter in ms. The greater the
amount of time used, the greater the attenuation possible for
the ﬁlter, but the run time increases correspondingly. Smaller
ﬁlters may have fewer artifacts and run faster, but will not
give as much attenuation. The range of values for this
parameter is from 0 to the maximum time of the input data.
This parameter can be changed interactively during program
execution. However, only a single value can be input to F-K
Filter for all ﬁlters.
Spatial extent of F-K ﬁlter (traces)
Enter the spatial extent of the F-K ﬁlter in traces. The greater
the number of time samples used, the greater the attenuation
possible for the ﬁlter, but run time increases correspondingly.
Smaller ﬁlters may have fewer artifacts and run faster, but
will not give as much attenuation. The range of values for this
parameter is from 1 to the number of traces of input data.
This parameter can be changed interactively during program
execution. However, only a single value may be input to F-K
Filter for all ﬁlters.

Filter Response
The response of the ﬁlter is viewed as the impulse response,
the ﬁltered output, or both. Parameters used in the ﬁlter
design can be changed. Remember that only a single set of
ﬁlter parameters can be applied in the F-K Filter program,
although the polygonal speciﬁcations of the ﬁlter may
change.
• Parameters pops up a dialog box to change the following
four ﬁlter design parameters:
Filter Mode: Pass/Reject.
Percent ﬂat for windowing: Enter 100% to not window
the ﬁlter, 0% to window the ﬁlter using Hanning taper
from the center of the ﬁlter, 50% to apply a Hanning
taper starting halfway between the center and the edge
of the ﬁlter.
Time length in ms, which may range from 0 to the
maximum time of the data. The value will be rounded
down to an odd sample number.
Spatial width in traces, which may range from 1 trace
