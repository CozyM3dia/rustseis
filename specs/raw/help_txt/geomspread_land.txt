Gap Deﬁnition Methods
In ProMAX® 2D, Gap Chan Dlt and Gap Size Dlt columns
have been added to the Sources spreadsheet for deﬁning a
gap for a shot location. A gap is created in the ﬁeld by not
recording into a given number of receiver stations
immediately preceding and following the shot (or source
array) location. This reduces the surface wave noise that
would likely contaminate and overdrive the geophones at
these receiver stations.
However, Gap Chan Dlt and Gap Size Dlt are not used if you
select the Auto 2D option from the Sources spreadsheet. You
must use multiple pattern cards where the gap moves
through the spread when using Auto 2D.
With the addition of the Gap Chan Dlt and Gap Size Dlt
columns, you have two methods for deﬁning a gap in a
receiver pattern:
Method 1 - Static Gap Deﬁnition: Deﬁne a gap by the jump
in the receiver station numbers within the pattern deﬁnition
entered in the Patterns spreadsheet. A new pattern deﬁnition

Patterns
The Patterns button opens the PAT Ordered Parameter File
(OPF) spreadsheet for entering, importing, or editing the
deﬁnition of receiver patterns for each shot. The Patterns
spreadsheet is not available if you have selected Assign
Midpoints By: Existing index number mappings in the
TRC within Setup.
The receiver pattern is applied to a given shot in the Sources
spreadsheet according to the selected midpoint assignment
mode in the Geometry Setup window. Pattern numbers in the
Sources spreadsheet must correspond to pattern numbers in
the Patterns spreadsheet and vice versa. For 2D Land
Geometry, there are two midpoint assignment modes which
utilize pattern deﬁnitions.
• Assign Midpoints By: Matching pattern numbers
using ﬁrst live chan and station
The pattern is hung from 1st Live Chn and 1st Live Sta
speciﬁed in the Sources spreadsheet. Live receivers for a
shot are then calculated from the relative difference
between stations in the pattern and their corresponding
channel numbers.
• Assign Midpoints By: Matching pattern numbers
using pattern station shift
The pattern is shifted from its deﬁned location in the
Patterns spreadsheet by the Pat Shift column in the
Sources spreadsheet for each shot. This allows for the
pattern to be rolled on or off of the deﬁned receiver
stations in the Receivers spreadsheet. The range of
receivers not located during geometry assignment is
listed in the output for each shot.
If no information has previously been entered into the
Patterns spreadsheet, clicking on the Patterns button for the
ﬁrst time will open a Recording System Channels dialog box
in addition to the Patterns spreadsheet. Enter the requested
information prior to running the Assign midpoints step in
Bin. If these values need to be edited, this dialog box can be

Binning the Data
Straight line binning assumes that the data were acquired on
a nearly constant azimuth and that shots and receivers are
referenced to a common surface station numbering scheme.
Speciﬁcally, the SOU_SLOC and SRF_SLOC headers must be
referenced to the same station coordinate system. The CDP
bin number assigned to each trace is the sum of the shot and
receiver station numbers. The CDP bin coordinate is the
mean of the midpoint coordinates of all the traces
contributing to that CDP bin.

TraceQC
The TraceQC button opens the TRC Ordered Parameter File
(OPF) spreadsheet. This spreadsheet is a window into the
database TRC OPF which can actually contain more
attributes than are shown by this spreadsheet. The database
TRC OPF contains all trace speciﬁc attributes for this
ProMAX® line. Some of the attributes are geometry related,
while others are not. Only attributes pertaining to the your
particular type of geometry are shown in the TRC
spreadsheet. Most of the attributes in this spreadsheet are
internally computed and are only for quality control viewing.
Attributes which cannot be edited have an * in the column
name. For example, CMP X* cannot be edited, whereas FB
Pick can be edited.
Columns in the TRC OPF spreadsheet are initialized by one
or more of the following steps:
• running Extract Database Files
• successful completion of Assign Midpoints in Bin
• successful completion of Bin Midpoints in Bin
• importing UKOOA data using File/UKOOA Import
• using File/LOOKUP Indexing
