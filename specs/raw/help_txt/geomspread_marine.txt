Auto-2D
The Auto-2D button opens the Auto Marine 2D Geometry

Before you use Auto-2D, you should decide if it is

the Sources spreadsheet.

Patterns
The Patterns button opens the PAT Ordered Parameter File
(OPF) spreadsheet for entering, importing, or editing the
deﬁnition of receiver patterns for all shots.
The Patterns spreadsheet is not available if you have
selected Assign Midpoints By: Existing index number
mappings in the TRC within the Setup. For 2D marine
geometry, only Assign Midpoints By: Matching pattern
number in the SIN and PAT spreadsheets utilizes pattern
deﬁnitions.
Marine pattern deﬁnition differs substantially from the land
pattern deﬁnition. First, there is only one receiver pattern
allowed per survey. Second, source patterns can be deﬁned
in addition to the receiver pattern. There can be any number
of source patterns. All patterns are deﬁned relative to the X
and Y coordinates in the Sources spreadsheet.

The 2D marine receiver pattern requires entries in the Min
Chan, Max/Gap Chan, Chan Inc, Grp Int, X Offset, and Y
Offset columns. The receiver pattern does not have an entry
in the Src Pattern column.
The Min Chan, Max/Gap Chan, and Chan Inc columns
specify the range of channel numbers to assign to a
corresponding range of receiver stations. The relative
positions for each channel are deﬁned by the Grp Int, X
Offset, and Y Offset columns. These values are then used
with the X and Y values in the Sources spreadsheet, as well
as any source pattern deﬁnitions in the Patterns
spreadsheet, to determine the absolute coordinates of each
receiver for a given shot.
Source patterns can be deﬁned by entering values in the Src
Pattern, X Offset, and Y Offset columns. These column
entries must be in separate spreadsheet rows from the
receiver pattern row.

Binning Parameters
The following parameters will highlight according to the
Binning option you chose under Binning.
• Source Station Tie to CDP Number is the source station in the Sources spreadsheet used to tie the CDP
number entered in CDP Number Tie to Source Station.
Enter 0 for the ﬁrst live CDP number to be one.
• CDP Number Tie to Source Station is the CDP number
to tie the above source station. Enter 0 for the ﬁrst live
CDP number to be one.
• Distance Between CDPs is the interval in ft. or m used
to bin the midpoints. For typical CDP spacing, use one
half of the nominal receiver spacing.
The following offset binning parameters create the OFB
(Offset Bin) Database order. This enables traces to be
grouped together by offset range beginning at Min Offset
Bin Center and continuing up through Max Offset Bin
Center, incrementing by the Offset Bin Center
Increment. The OFB OPF is necessary for Surface
Consistent Amplitude Analysis and Surface
Consistent Decon.
The default is preset defaults, or the receiver interval
from Setup and NChans from Patterns. If the receiver
interval is not in Setup, the program uses 100 for the
Offset Bin Increment, 50 for the Min Offset Bin Center,
and 9950 for the Maximum offset Bin Center. If receiver
interval is in Setup, the program uses the receiver
interval for Offset Bin Increment, one half receiver
interval for Min Offset Bin Center, and receiver interval
times (the number of channels minus 1.5) for Maximum
offset Bin Center. To use values different then these
select user deﬁned OFB parameters and enter the new
values.
• Offset Bin Increment is the distance between centers of
offset bins in ft. or m. Offset Bin size, other then ﬁrst
and last, is equal to Offset Bin Increment.

minus one half the Offset Bin Increment are assigned to

(OPF) spreadsheet. This spreadsheet is a window into the
database TRC OPF which can actually contain more
attributes than are shown by this spreadsheet. The database
TRC OPF contains all trace speciﬁc attributes for this
ProMAX® line. Some of the attributes are geometry related,
while others are not. Only attributes pertaining to the your
particular type of geometry are shown in the TRC
spreadsheet. Most of the attributes in this spreadsheet are
internally computed and are only for quality control viewing.

Patterns
The Patterns button opens the PAT Ordered Parameter File
(OPF) spreadsheet for entering, importing, or editing the
deﬁnition of receiver patterns for each shot. The Patterns
spreadsheet is not available if you have selected Assign
Midpoints By: Existing index number mappings in the
TRC within Setup.
The receiver pattern is applied to a given shot in the Sources
spreadsheet according to the midpoint assignment mode in
the Geometry Setup window. Pattern numbers in the Sources
spreadsheet must correspond to pattern numbers in the
Patterns spreadsheet and vice versa. For 3D marine
geometry, there is one midpoint assignment mode which
utilizes pattern deﬁnitions.
• Assign Midpoints By: Matching pattern number in
the SIN and PAT spreadsheets
Patterns are assigned to shots by matching the number
in the Pattern column in both the Sources and Patterns
spreadsheets. For a given pattern number, a range of
channel numbers map to a range of receiver stations.
Marine pattern deﬁnition differs substantially from the land
pattern deﬁnition. First, there is only one receiver pattern
allowed per survey. All receiver pattern entries apply to the
one pattern to use by all shots. Second, the Patterns
spreadsheet allows for source pattern deﬁnitions in addition
to the receiver pattern. There can be any number of source
patterns. Patterns are deﬁned for the receiver locations on
the streamer and the source locations relative to the X and Y
coordinates for each shot in the Sources spreadsheet.

All pattern information is described in terms of the X Offset
and Y Offset columns. The X and Y offsets are distances
relative to the vessels position (X and Y columns in the
Source spreadsheet) in the direction of the streamer azimuth
(Strmr Azmth column in the Sources spreadsheet) at the
time when a shot took place. The X offset is deﬁned as an
offset distance in the direction of the streamer azimuth.
Positive X values are towards the tail buoy position and
negative X values are towards the bow of the vessel. The Y
offset is deﬁned to be an offset distance perpendicular to the
streamer azimuth. Positive Y values are to the right to the line
deﬁned by the vessels position and the streamer azimuth as
you look from the stern of the vessel towards the tail buoy
(the port side of the vessel). Negative Y values are to the left
(the starboard side of the vessel).

spreadsheet: Min Chan, Max/Gap Chan, Chan Inc, Src

deﬁne a range of channel numbers to assign to a

• OFB* is the offset bin number of the trace. Positive and
negative source-receiver offsets are binned as absolute
offsets and a sequential bin number is assigned to each
offset bin. These values are computed in the Bin midpoints step in Bin from entries in the 3D Marine Midpoint Binning window.
• OFB_LTBL* is a numeric counter ranging from one to
the maximum number of Mark Blocks in the TRC OPF
spreadsheet. It is computed and used internally to relate
one attribute value to another. This allows for fast database access during processing. This entry should be
ignored for geometry assignment and quality control.
