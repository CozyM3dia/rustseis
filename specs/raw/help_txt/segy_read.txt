SEG-Y Input
SEG-Y Input reads data from tapes approximately
conforming to the SEG-Y standard.

Theory
This process also reads SEG-Y disk image ﬁles, in formats
produced by various workstations including Sierra,
Landmark, MS-DOS, Charisma, Prakla, and Western. It
offers the non-standard option to recover more than one ﬁle
from a SEG-Y tape.
Read the Seismograph Instrument Parameters section for
information on transduction, coding, and skew corrections.

Parameters
Type of SEG-Y?
Select the type of data storage that has been used for the
input data. Choose disk type carefully, if storage is disk
image. The choices are:
• Standard ﬁxed trace length reads from a standard
SEG-Y tape. This is the default.
• Standard variable trace length reads from a standard
SEG-Y tape.
• Sierra reads from a Sierra SEG-Y ﬁxed record length
disk ﬁle.
• Landmark TOD reads from a Landmark TOD SEG-Y
ﬁxed trace length disk ﬁle. This option has one master
control block and one or more slave control blocks at the
end of the ﬁle.
• Western reads from a Western SEG-Y variable record
length disk ﬁle.
• MS-DOS reads from a MS-DOS SEG-Y ﬁxed trace length
disk ﬁle.
• Prakla reads from a Prakla SEG-Y variable trace length
disk ﬁle.

Invert normal byte order correction?
The SEG-Y standard requires conforming ﬁles to explicitly
encode data in big-endian byte order. However some systems
violate this requirement. By selecting Yes, you can
compensate for little-endian input.

Input multiple ﬁles from tape(s)?
Select Yes to input all records/ﬁles on the tape. Also specify
Yes if the SEG-Y ﬁle spans multiple tapes and you need to
mount additional tapes. The default is No, the job will end
after encountering an EOF.
Multiple ﬁle selection
This appears if Yes to Input multiple ﬁles from tapes.
Select whether to input ﬁles/tapes based upon a sequential
ﬁle count. The choices are:
• Input All inputs all ﬁles/tapes.
• Select range selects ﬁles/tapes.
The SEG-Y standard is to have one ﬁle per tape and a line
typically spans more than one tape. The default is to set the
multiple ﬁles ﬂag to Yes and the ﬁle selection to Input All.
Specify input ﬁles list
This appears if Select to Multiple ﬁle selection. Enter the
ﬁles to read from the tape. This allows you to retrieve selected
ﬁles from the tape by counting the ﬁles EOFs on the tape.
Note: The maximum number of ﬁles that you can currently
specify is 50000.
For example, to skip the ﬁrst two datasets and read in the
third, the entry would be:
3/

Note: This example could also be used to read data from a
tape where there are two consecutive EOFs between the ﬁrst
two datasets on the tape, and you wish to read in the second.
For example, to read the ﬁrst, third and ﬁfth ﬁles, the entry
would be:
1,3,5/

To read ﬁles 1 through 10, the entry would be:
1-10/

Maximum data block size in bytes
Enter the maximum block size encountered when reading
from tape. The default is 65535 bytes and works for all tapes
following the SEG-Y standards.
Note: For values greater than 65535, you must have a long
block driver.
Number of errors in a row before Aborting job
Enter the number of errors in a row before aborting the job.
Enter 0 to ignore all errors. Any value greater than 0 will
output dead traces until this value is reached.
Samples per data trace (override binary header)
Enter the number of samples in a data trace. Enter 0 to get
from SEG-Y binary header bytes 21-22.
This parameter is intended for the case when bytes 21-22 of
the binary header are incorrect. The number of samples
speciﬁed must represent the exact number of samples.
Note: For Sierra format, this value is required. You must
enter the number of samples in the data traces.
Store reel header in processing history?
Select Yes to store the 3200 byte SEG-Y reel header (EPCDIC)
in the processing history. The header can then be displayed
within the history viewer and the side label CGM plot. Also
the header can be output to a SEG-Y tape using the SEGY
Output process. The 400 byte binary header is written into
the ﬁle bhed in the ﬂow directory, which is useful when
processing SEG-Y data from input to output.
Input Auxiliary traces?
Select Yes to input the auxiliary traces. Select No to omit the
auxiliary traces. Auxiliary traces are designated by negative
trace numbers.
Get Channel number from trace headers?
Select Yes to get the channel number from the SEG-Y trace
headers. Select No to number the channels sequentially

Input trace Format?
Select the input data format, or instruct the program to read
the format information from the SEG-Y binary header. The
normal choice would be to read the information from the
binary header, but this can be incorrect. If that happens, you
will have to specify the format. The choices are:
• Get from header gets the trace format from binary
header.
• IBM Real is 4-byte IBM Floating Point SEG-Y.
• 4 byte Integer is 4-byte Integer SEG-Y.
• IEEE Real is 4-byte IEEE Floating Point SEG-Y (nonstandard).
• 2 byte Integer is 2-byte Integer SEG-Y.
• 4 byte w/Gain is 4-byte SEG-Y Fixed Point with Gain
Code.
• 2 byte ﬂoat is 2-byte ﬂoating point SEG-Y (non-standard).
• 1 byte Integer is 1-byte Integer SEGY-Y (non-standard).
The 2 byte ﬂoat and 1 byte integer formats are nonstandard SEGY. These formats cannot be found by using the
Get from header option. If your data is one of these formats
you must select the correct one.
Apply trace weighting factors (2**-N)?
Select Yes to apply the millivolt conversion factor stored in
header bytes 169-170 of the standard SEG-Y header to ﬁxed
point sample formats. The default setting of Yes is the normal
mode of operation.
Select No to disable application of standard SEG-Y trace
weighting factors stored in bytes 169-170 of the trace
headers. This option is used to support reading non-standard
SEG-Y data.

Input Primary selection choice?
Select the key on which the input trace list is speciﬁed. The
choices are:
• Input All inputs all ﬁle numbers on this tape, or multitape input.
• FFID (File No.) selects input records based on SEGY ﬁeld
ﬁle number. To be used primarily for shot gathers.
• CDP selects input traces based on their common depth
point number. To be used primarily for CDP gathers.
• Source Index No. selects input records based on the
sequential source number within the tape. To be used
primarily for shot gathers.
• Channel selects input traces based on their trace, or
channel number.
• Receiver selects input traces based on their receiver
surface location number. To be used primarily for
receiver gathers.
• Line trc. seq. no. selects input traces based on their
ProMAX® sequential trace number within the line.
• Trc. seq. no. selects input traces based on their ProMAX® sequential trace number within the tape.

primary selection choice. Access the text editor to deﬁne

Since data from a tape/ﬁle is input sequentially, you should
try to build the list based upon sequential location within a
ﬁle. If the primary selection choice is decreasing within the
tape/ﬁle then the list should be decreasing. For example:
100-1/

Input Secondary selection choice?
Select a secondary selection choice. The choices are:
• None uses no secondary sort key. All channels/traces
are input.
• Channel inputs a subset of the channels in a record.

Use the coordinate scalar?
Select Yes to apply the coordinate scalar (bytes 71-72) to the
coordinates (bytes 73-88) when reading SEGY trace headers.
Choose Yes for a standard SEGY header.
Note: The location coordinates: SOU_X, SOU_Y, REC_X,
REC_Y, CDP_X and CDP_Y are stored as 4 byte integers in
SEG-Y trace headers. Due to the storage type, we recommend
that this option be left at its default value of Yes.
Use the Rev 1 time scalar?
Select Yes to apply the time scalar ( bytes 215-216 in the Rev
1 header) to the statics, lag times and mutes (bytes 95-114)
when reading the SEG-Y trace headers. The time scalars are
ignored if the input is not SEG-Y Rev1 or higher. (See SEG-Y
Rev 1 header table.)
Scan range of all header words?
Select Yes to scan the range of all possible header entries in
the 240 byte trace header as 2 byte and 4 byte integers and 4
byte and 8 byte ﬂoating point values. A summary of the
minimum and maximum values in each possible header slot
is printed at the end of the job.
Use SEG-Y Rev 1 header mapping?
Choose one of Autodetect, NO, or YES to control SEG-Y
revision 1 processing. The default is to automatically detect
any SEG-Y Revision 1 ﬂags in the input. (See SEG-Y Rev 1
header table.)
Remap SEG-Y headers?
Select Yes to input/override/remap SEG-Y trace header
values. There is a difference in the amount of ﬁelds you need
to remap in SEG-Y Input and SEG-Y Output. SEG-Y input
requires and extra keyword description ﬁeld to be entered.
SEG-Y Output now ignores the extra ﬁeld and runs correctly
if you cut and paste SEG-Y Input headers into SEG-Y
Output.

Input/override trace header entries
This appears if Yes to Remap SEGY headers. Enter
ProMAX® header entries to input or override from the SEG-Y
trace header, using user supplied format and position. The
default values in this ﬁeld are changed signiﬁcantly if
theType of SEG-Y selected is Input/Output. Header entries
are created if they do not exist. Position is anywhere inside
the 240 byte SEG-Y trace header. An override entry consists
of ﬁve ﬁelds plus a / at the end of each entry. Each ﬁeld is
separated by a comma.
Example: rms_amp, RMS AMPLITUDE,4R,IEEE,204/

Field 1: rms_amp is the name of the ProMAX® header word.
This can be a new word deﬁned by you or an existing word as
deﬁned in header.inc. This ﬁeld can be 1 to 8 characters.
Field 2: RMS AMPLITUDE is the description of the ProMAX®
header word. If you are overriding a current header word that
already exists in header.inc, this ﬁeld may be left blank. This
ﬁeld can be 1 to 32 characters.
Field 3: 4R is the format of the value in the SEG-Y header.
This ﬁeld must contain 2 characters such as 4R or 2I. You
may select any of the following for this ﬁeld:
• 1I (1 byte integer)
• 2I (2 byte integer)
• 3I (3 byte integer)
• 4I (4 byte integer)
• 4R (4 byte real)
• 8R (8 byte real)
• #C (1-9 printed numeric characters)
• #A (1-9 characters of any type)
#C ﬁelds are decoded using a format appropriate to the
numeric type of the destination ProMAX® header word. #A
ﬁelds are copied directly into one or more consecutive
ProMAX® header words. EBCDIC characters are converted
to ASCII prior to #C or #A processing.
Field 4: IEEE is the data representation of a real value in the
SEGY header. This ﬁeld is valid for 4R and 8R values only.
